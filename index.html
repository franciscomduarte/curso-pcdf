Antes de começar

Pré-requisitos

O que cada aluno precisa ter instalado e configurado antes da primeira aula. A preparação é feita uma vez só e leva cerca de 20 minutos.

🐍

Python 3.10 ou mais novo

A linguagem de todo o código do curso. Já vem com pip e venv (ambientes virtuais), usados em toda aula. python.org/downloads

📝

Um editor de código

VS Code é o recomendado — gratuito, com terminal integrado. PyCharm, Sublime ou similar também servem. code.visualstudio.com

🔀

Git

Para baixar o repositório do curso (git clone) e acompanhar as atualizações. git-scm.com/downloads

⌨️

Terminal

Saber abrir o terminal do sistema e rodar comandos básicos (cd, python, pip). Windows: PowerShell. macOS/Linux: Terminal.

Chave de API da OpenAI — opcional, não obrigatória

Todos os laboratórios rodam offline, com um LLM falso e determinístico, quando não há chave configurada. A OPENAI_API_KEY só aparece nas Aulas 1 a 3, e apenas para quem quiser ver a resposta do modelo real no lugar do mock. As Aulas 4 a 10 não usam LLM nenhum.

Quanto comprar de créditos, se for usar a API

  • Modelo padrão: gpt-4.1-mini — cerca de US$ 0,40 por milhão de tokens de entrada e US$ 1,60 por milhão de saída.
  • Os exemplos processam textos curtos de ocorrências sintéticas: cada chamada custa uma fração de centavo.
  • Rodar todos os laboratórios das Aulas 1 a 3 com a API real, várias vezes, sai por poucos centavos de dólar no total.
  • Recomendação: comprar o mínimo da OpenAI — US$ 5. É a menor compra que a plataforma aceita e cobre o curso inteiro com folga de sobra.

Preços e valor mínimo verificados em agosto de 2026 (developers.openai.com/api/docs/pricing · Central de Ajuda da OpenAI). Os valores podem mudar — confira no seu painel antes de comprar.

Integrações opcionais, por aula

Cada aula tem um caminho "real" à parte, com a tecnologia de produção de verdade. Nenhum é obrigatório — o núcleo de toda aula roda só com Python. Instalam-se com pip install -r requirements-opcionais.txt dentro da pasta da aula.

  • Aula 2: um broker MQTT (via Docker) para main_mqtt.py; grpcio para o grpc_demo/.
  • Aula 3: o SDK oficial mcp para o mcp_real/.
  • Aula 6: o pacote langgraph para o langgraph_real/.
  • Aulas 8 e 9: Docker + um cluster Kubernetes local (kind ou minikube) para os k8s_real/.

Princípio do curso

Uso responsável

⚠️ Ponto de atenção — uso responsável

Os sistemas construídos nesta unidade são ferramentas de apoio: recuperam informação, organizam, classificam, extraem, correlacionam e geram rascunhos. Eles não determinam culpabilidade, autoria, prisão, indiciamento ou medida cautelar, e não classificam definitivamente ninguém como suspeito.

A decisão em situações sensíveis é sempre humana, com supervisão, validação, rastreabilidade, auditoria, controle de acesso e proteção de dados (LGPD). Todo o material usa dados fictícios.
