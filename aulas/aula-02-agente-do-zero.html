Um agente do zero, sem framework

Frameworks como LangGraph e CrewAI só embrulham um loop simples. Nesta aula você escreve esse loop na mão — e nunca mais vai ver um agente como caixa-preta.

roda sem chave de API Python puro projeto-espinha

A ideia central

O loop do agente

Todo agente — do mais simples ao mais avançado — repete cinco passos. Guarde esta figura: ela é o mapa do arquivo que vamos escrever.

▶ Como rodar

Todos os exemplos usam um LLM falso e roteirizado (o MockLLM): rodam na hora, sem chave de API, com resultado sempre igual — ótimo para aula. No fim há um interruptor para trocar pelo Claude de verdade.

Peça 1

Ferramentas: só funções + descrição

Um agente não "tem poderes". Ele escolhe entre as funções que nós registramos. Uma ferramenta é uma função Python comum com um nome e uma descrição.

ferramentas.py
from dataclasses import dataclass
from typing import Callable

def buscar(consulta: str) -> str:
    """Busca 'falsa' numa base fixa — no lugar de uma API/RAG."""
    base = {"população rio verde go": "219550", "capital de goiás": "Goiânia"}
    return base.get(consulta.strip().lower(), "Nenhum resultado encontrado.")

@dataclass
class Ferramenta:
    nome: str
    descricao: str
    funcao: Callable[..., str]

FERRAMENTAS = [
    Ferramenta("buscar", "Busca um fato. Args: consulta", buscar),
    # calcular(...) fica no arquivo completo
]

Peça 2

O LLM atrás de uma interface

Este é o truque que separa lógica do agente de inteligência do modelo: o agente só conhece um método completar(). Podemos plugar um LLM falso (aula) ou o Claude real (produção) sem mudar o agente.

Mesma interface, duas implementações. O agente não sabe (nem precisa saber) qual está plugada.

llm.py
import json
from typing import Protocol

class LLM(Protocol):
    def completar(self, mensagens: list) -> str: ...

class MockLLM:
    """LLM falso: devolve respostas fixas conforme o estágio da conversa."""
    def completar(self, mensagens: list) -> str:
        n = len([m for m in mensagens if m["role"] == "tool"])
        if n == 0:
            return json.dumps({"pensamento": "Vou buscar a população.",
                "acao": {"ferramenta": "buscar",
                         "args": {"consulta": "população Rio Verde GO"}}})
        return json.dumps({"pensamento": "Já tenho o dado.",
                           "resposta_final": "Rio Verde tem ~219.550 habitantes."})

Peça 3 · o coração

O loop do agente, em código

Repare em dois detalhes que voltam na Aula 6: o max_passos (trava anti-loop — sem ela, um agente confuso rodaria para sempre) e o json.loads (parsing frágil de propósito — o que acontece se o modelo fugir do formato?).

agente.py
class Agente:
    def __init__(self, llm, ferramentas, max_passos: int = 6):
        self.llm = llm
        self.registro = {f.nome: f for f in ferramentas}
        self.max_passos = max_passos       # trava anti-loop

    def executar(self, tarefa: str) -> str:
        mensagens = [{"role": "user", "content": tarefa}]
        for passo in range(1, self.max_passos + 1):
            bruto = self.llm.completar(mensagens)
            dados = json.loads(bruto)              # parsing frágil (Aula 6)
            if "resposta_final" in dados:
                return dados["resposta_final"]     # condição de parada
            acao = dados["acao"]
            ferramenta = self.registro[acao["ferramenta"]]
            observacao = ferramenta.funcao(**acao["args"])
            mensagens.append({"role": "assistant", "content": bruto})
            mensagens.append({"role": "tool", "content": observacao})
        return "Limite de passos atingido."       # rede de segurança

Executando

O traço da execução

Rodando python agente_do_zero.py, o agente resolve "Quantos habitantes tem Rio Verde (GO)? Qual a raiz quadrada disso?" em três passos. Este é o resultado real:

saída do terminal
--- passo 1 ---
pensamento: Preciso da população de Rio Verde (GO). Vou buscar.
acao: buscar({'consulta': 'população Rio Verde GO'}) → 219550

--- passo 2 ---
pensamento: Tenho 219550. Agora calculo a raiz quadrada.
acao: calcular({'expressao': '219550 ** 0.5'}) → 468.56

--- passo 3 ---
pensamento: Já tenho população e raiz. Posso responder.

=== RESPOSTA FINAL ===
Rio Verde (GO) tem ~219.550 habitantes; a raiz quadrada é ~468,56.

Note como o agente encadeia ferramentas: buscou o número, usou o número para calcular, e só então respondeu. Ninguém programou essa ordem — o modelo decidiu.

Produção

Trocando o mock pelo Claude real

Quando quiser inteligência de verdade, plugue o Claude. O agente não muda em nada — só a implementação da interface.

claude_llm.py · pip install anthropic · ANTHROPIC_API_KEY
import anthropic

class ClaudeLLM:
    def __init__(self, modelo: str = "claude-sonnet-5"):
        self.cliente = anthropic.Anthropic()   # lê ANTHROPIC_API_KEY do ambiente
        self.modelo = modelo

    def completar(self, mensagens: list) -> str:
        # separa o system das demais e converte 'tool' em texto de observação
        sistema = "Responda SEMPRE só um objeto JSON (acao ou resposta_final)."
        msgs = [{"role": "user" if m["role"] == "tool" else m["role"],
                 "content": m["content"]} for m in mensagens if m["role"] != "system"]
        r = self.cliente.messages.create(model=self.modelo, max_tokens=1024,
                                         system=sistema, messages=msgs)
        return r.content[0].text
⚠ Ponto de aula

Com o Claude real, o modelo às vezes escreve texto fora do JSON — e aí o json.loads quebra. Guarde essa dor: é exatamente ela que motiva saídas estruturadas e avaliação na Aula 6.
